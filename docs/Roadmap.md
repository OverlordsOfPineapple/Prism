# Prism Roadmap

## 2.1 — Foundation

- Canonical local workspace.
- Git baseline and repeatable scripts.
- Documentation and health checks.
- Stable live development workflow.

## 2.2 — Cinematic

- Typography, spacing, hierarchy, motion, poster presentation, hover states, and restrained depth.

## 2.3 — Discovery

- Progressive filter controls, stronger recommendations, curated collections, hidden gems, forgotten classics, and clearer decision support.

## 2.4 — Television

- Shared media model with television-specific metadata and discovery.

## 2.5 — Books

- Book metadata and discovery through the common Prism experience.

## 2.6 — Comics

- Comic-series discovery through the common media architecture.
